Plan 1 must be revised before execution: bean-cycle tables, slot-based recipes, slot-aware and giveaway-aware `record_sale`. The spec covers six subsystems. Each gets its own plan, and each plan produces working, tested software on its own. Only Plan 1 is written in full. Each later plan is written when its predecessor is merged, so it can build on the real code and on what was learned.
